# Sistema Bancário em Python

## Sobre o projeto

Sistema bancário desenvolvido em Python para praticar lógica de programação, funções, estruturas condicionais e validação de operações.

## Funcionalidades

- Depósito de valores.
- Saque com validação de saldo.
- Consulta de extrato.
- Limite de saques.

## Tecnologias utilizadas

- Python 3
- Variáveis
- Estruturas condicionais
- Laços de repetição
- Listas

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python sistema_bancario.py
```

## Objetivo

Praticar os fundamentos da programação Python por meio da construção de um sistema bancário simples.
