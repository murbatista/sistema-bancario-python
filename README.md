# Sistema Bancário em Python

## Sobre o projeto

Projeto desenvolvido durante os estudos de Python, com base no desafio de sistema bancário da DIO. O objetivo é praticar lógica de programação, funções e validação de operações.

## Funcionalidades

- Depósito de valores positivos.
- Saques com limite de R$ 500,00 por operação.
- Limite de três saques.
- Verificação de saldo disponível.
- Extrato com histórico de movimentações e saldo atual.
- Tratamento de entradas numéricas inválidas.

## Tecnologias utilizadas

- Python 3
- Funções
- Estruturas condicionais
- Laços de repetição
- Listas
- Tratamento de exceções (`try` e `except`)

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python sistema_bancario.py
```

## Objetivo de aprendizagem

Praticar os fundamentos da programação Python por meio da criação de um sistema bancário simples, organizado e com validações básicas.
